# GigConnect – Frontend

React 19 and Vite client for GigConnect. See the [root README](../README.md) for full setup.

```bash
npm install
npm run dev      # start dev server on http://localhost:5173
npm run build    # production build into dist/
npm run lint     # ESLint
```

Set `VITE_API_URL` in `.env` (see `.env.example`) to point at a backend other than `http://localhost:5000/api`.
